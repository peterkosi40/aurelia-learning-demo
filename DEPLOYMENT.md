# Deployment — Aurelia Learning

This is a static website. Upload every file in this folder to the root of a new GitHub repository, including the JPG image files.

## Cloudflare Pages
- Create a new Pages project connected to the repository.
- Framework preset: None
- Build command: leave blank (or `exit 0` if required)
- Build output directory: `/` or `.` (the repository root)
- Deploy.

After the final public URL is known, add that URL as the canonical URL in `index.html`, commit the change, and redeploy.

The enrolment form is a demonstration and opens the visitor's email app; it does not save submissions in a database.
