# Aurelia Learning — Website Demo

A responsive fictional online-learning website built as a portfolio sample.

## Files
All files, including the locally bundled JPG photography, are intentionally kept in this same folder so the project can be uploaded easily from a phone.

## Features
- Responsive desktop, tablet and mobile layouts
- Course category filters and course search
- Course preview dialogs
- Mobile navigation
- Enrolment enquiry form that opens a prefilled email
- Generated educational photography featuring a diverse mix of people

## Local preview
Open `index.html` in a modern browser.

This is a fictional demonstration, not a real learning provider. Course names, instructors and course details are illustrative.
